Type pairing
Fredoka for the stage
Varela Round for everything spoken quietly — labels, names, timers. Both are round-terminal so strokes read as rolled clay, and both hold up through 720p screen-share compression.
Material model · every element is one rule
submit
  • uneven corner radii — never symmetric
  • top-light inset + bottom occlusion inset
  • hard offset shadow: sits on the table
  • ±1–2° rotation per element
  • no pure white, no pure black, no gradients
Signature element
Losers live upside down. Every reveal flips the winner right-side-up; the loser rotates 180° and stays that way — on the reveal, on the scoreboard, in the recap. Motion animates on twos (~12fps, steps()), with squash on landing and overshoot on settle.
